# 경주시 서무 AI 업무도우미 · 상시학습 등록 자동화

공문과 참석자 명단을 읽어 교육정보를 검토하고, 선택한 부서의 상시학습 등록용 Excel을 생성하는 교육·시연용 프로젝트입니다. 현재 AI API는 사용하지 않습니다. 초과근무수당 도우미는 준비 중 안내만 제공합니다.

**공개 사이트에는 실제 개인정보·내부 비공개 자료를 입력하지 마세요. 가상자료로 실습하세요.**

## 주요 기능

- PDF·ODT·HWPX 공문 텍스트와 교육정보 후보·근거 추출
- 추출값 직접 수정, 공식 교육유형 목록 선택, 교육정보 확인·적용
- XLSX 참석자 명단의 부서·성명 컬럼 자동 인식, 누락 안내와 모호한 후보 선택
- 부서 검색·선택과 대상자 선별, 부서 내 동명이인 확인
- 선택적인 2/3컬럼 개인식별번호 명부 조회
- 기준 양식 복제, D열 수식 유지, 결과 Excel 다운로드
- 파일 끌어놓기·개별 선택 해제·오류 안내·진행 단계 표시
- 경주 8색 기반 포털과 시연용 공용 암호 진입 화면

## 설치 및 기본 로컬 실행

프로젝트 폴더를 받은 뒤 Python을 준비합니다. 기본 웹 실행기는 Python 표준 라이브러리만 사용하며 별도 Python 패키지 설치가 필요 없습니다. 최신 Chrome 또는 Edge를 사용하세요.

프로젝트 루트에서:

```powershell
python -B run_web.py
```

- 주소: http://127.0.0.1:8001/
- 포털에서 **상시학습 도우미**를 선택합니다.
- 종료: 터미널에서 `Ctrl+C`
- 포트 변경: `python -B run_web.py --port 8010`
- localhost 전용 실행입니다. 기본 실행으로 다른 PC에 서비스하지 않습니다.
- 파일을 `file://`로 직접 열지 말고 HTTP 주소로 접속하세요.

현재 개발 PC에서 `python` 명령이 작동하지 않을 경우:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" -B .\run_web.py
```

이 경로는 현재 Codex 번들 설치 환경 전용입니다. 다른 PC에서는 설치한 Python 경로를 사용하세요.


검증값은 `site-demo/dist/demo-access.json`에 저장합니다. 같은 탭의 새로고침·페이지 이동에는 인증을 유지합니다. 변경 후 새로고침하면 이전 인증은 무효화됩니다. 탭 복제·세션 복원으로 인증이 이어질 수도 있습니다.

**이 암호창은 우회 가능한 시연용 화면이며 서버 접근 통제가 아닙니다.** 배포된 검증값·정적 자산은 방문자가 읽을 수 있습니다. 다른 서비스의 암호를 재사용하지 마세요. 로컬에서 암호를 바꿔도 외부 사이트에는 별도 배포 전까지 적용되지 않습니다.

## 사용 순서

1. 암호로 입장한 뒤 **상시학습 도우미**를 선택합니다.
2. 공문(PDF·ODT·HWPX)과 참석자 명단(XLSX)을 각 영역에서 선택하거나 하나씩 끌어놓습니다. 파일당 최대 20MB입니다.
3. 개인식별번호 명부는 선택입니다. 미첨부하면 B열은 빈셀입니다. 파일명 옆 ×는 선택만 해제하며 원본을 삭제하지 않습니다.
4. 명단 컬럼을 확인합니다. `소속/부서/부서명/소속부서`, `성명/이름`, 선택적인 `직급`이 명확하면 자동 연결합니다. 머리글 내부 공백도 무시합니다. 필수 컬럼이 없으면 안내에 따라 파일을 수정·교체합니다. 후보가 여러 개일 때만 작은 선택 영역에서 사용할 항목을 고릅니다.
5. 대상 부서를 목록에서 선택합니다. 디지털정책과가 목록에 있을 때만 기본 선택합니다. 검색어만 입력해서는 확정되지 않습니다.
6. **분석하기**를 누릅니다. 필수 파일이 없으면 해당 첨부 칸에 안내합니다.
7. **교육정보 검토·수정**에서 후보의 근거를 보고 교육명·날짜·인정시간·학습방법·공식 교육유형을 보완합니다. 후보 사용 버튼을 모두 누를 필요는 없습니다.
8. **교육정보 확인·적용**을 한 번 누릅니다. 정보 수정 후에는 다시 적용해야 합니다.
9. 필수교육·사회복지교육·참여유형을 확인합니다. 웹 기본값은 N/N/0입니다. 사회복지교육 Y는 현재 생성할 수 없습니다.
10. **상시학습 등록 Excel 생성 → 결과 Excel 다운로드**를 누릅니다. 미확인 상태라면 확인 버튼으로 이동합니다. 내려받은 내용을 검토하고 D열 수식 결과는 Excel에서 재계산해 확인하세요.

원본은 변경하지 않습니다. 웹 결과는 서버의 output 폴더가 아니라 브라우저에서 다운로드됩니다. 같은 이름의 다운로드 파일 처리는 브라우저 설정에 따르므로 저장 위치·파일명을 확인하세요. 새로고침·초기화하면 선택 파일과 결과 링크가 사라집니다. 컬럼 연결 설정도 파일 교체·초기화 시 해제됩니다.

파일을 직접 선택해 분석합니다. 파일 없이 진행하는 샘플 체험 기능은 제공하지 않습니다.

## 개인식별번호 명부

| 형식 | 필수 컬럼 | 조회 |
|---|---|---|
| 3컬럼 | 부서, 성명 또는 이름, 개인식별번호 | 부서+이름 정확히 일치 |
| 2컬럼 | 성명 또는 이름, 개인식별번호 | 부서 선별 후 이름만 정확히 일치 |

번호는 **텍스트 상수**로 준비하세요. 같은 조회 키가 여러 행이면 번호가 같아도 중복입니다. 조회 상태가 `matched`일 때만 B열에 입력하고 `duplicate/not_found/no_file/missing_id`이면 빈셀로 둡니다. 숫자·수식·오류 셀을 번호로 자동 확정하지 않습니다.

참석자 명단 컬럼 연결 UI는 번호 명부에는 적용되지 않습니다. 번호 명부는 위 컬럼명을 사용하세요.

## 보존된 Python CLI / 이전 FastAPI

기본 웹과 별도 구현입니다. Python 3.10 이상과 의존성을 설치합니다.

```powershell
python -m pip install -r requirements.txt
python -B src/preview.py --input-dir "입력폴더"
python -B src/preview.py --input-dir "입력폴더" --generate --employee-file "가상직원명부.xlsx"
```

- 입력 폴더에는 PDF 하나, 이름에 `참석자`와 `명단`이 포함된 XLSX 하나, `교육실적등록`과 `양식`이 포함된 XLSX 하나를 둡니다. 후보가 여러 개면 중단합니다. 루트에는 샘플이 여러 개 있으므로 별도 입력 폴더를 권장합니다.
- CLI는 소방교육 샘플의 엄격한 공문 형식, `소속/직급/성명` 명단을 대상으로 하며 대상 부서는 디지털정책과입니다. 웹의 ODT/HWPX·수동 컬럼 연결·유연한 검토 기능은 CLI에 없습니다.
- `--generate` 없이 미리보기만 표시합니다. 생성 시 N/Y, N/Y, 참여유형 0/1을 입력하며 참여유형에는 기본값이 없습니다.
- 번호 명부 미지정·파일 없음은 빈셀입니다. CLI 출력에는 조회된 번호가 표시될 수 있습니다.
- 결과는 기본 `output/`에 저장하고 이름 충돌 시 `_2`, `_3`을 붙여 덮어쓰지 않습니다.

이전 FastAPI UI가 필요한 경우에만 별도로 실행합니다.

```powershell
python -m uvicorn src.app:app --host 127.0.0.1 --port 8000 --no-access-log
```

이 경로는 파일을 Python 서버로 보내 임시 폴더에서 처리하고 결과를 output에 저장합니다. 기본 브라우저 방식과 혼동하지 마세요. 다운로드 링크는 30분 유효하며 결과 파일 자체는 output에 남습니다.

테스트는 가상 fixture와 샘플을 사용합니다. 읽기 규칙·조회 상태·컬럼 연결·결과 Excel·수식·양식 보존·덮어쓰기 방지를 검증합니다.

## 제한과 문제 해결

- HWP·스캔 문서 OCR·암호화 문서·XLS·매크로·AI 의미 해석은 미구현입니다.
- 본문 교육명이 없으면 ‘제목:’ 항목, 제목 항목도 없으면 파일명에서 규칙으로 후보를 제안합니다. 추정 출처를 확인·수정한 뒤 적용하세요. 일반적인 제목·여러 후보는 자동 확정하지 않으며 임의 오타·문맥을 AI로 해석하지 않습니다.
- 다중 날짜·교육유형 불일치는 자동 확정하지 않습니다. 시작/종료시간·장소는 등록 필수값이 아닙니다. 인정시간은 일정 차이가 아닌 공문·사용자 확인값을 씁니다.
- 학습방법은 집합과정(1), 사이버과정(2), 집합+사이버과정(3), 기타(4)를 지원합니다. 사회복지교육 Y는 추가 시간 확인 기능이 없어 차단됩니다.
- 컬럼 연결을 영구 저장하지 않으며 병합셀·비표준 명단의 모든 형태를 자동 복원하지 않습니다.
- 오류 시 확인 필요 문구와 파일 형식을 확인하세요. 배포 후 이전 화면이 남으면 Ctrl+F5로 새로고침하세요.
- `n.toHex is not a function` 문제에는 PDF Worker 호환 코드가 포함되어 있습니다. 그래도 실패하면 상세 오류와 브라우저 버전을 기록하세요.
- `prepare_assets.py`는 Codex 번들 Node 라이브러리 경로에 의존하는 개발자용 자산 재생성 도구입니다. 일반 사용 시 실행할 필요가 없습니다.

## 개인별 인정시간

명단에 시간 컬럼이 없으면 확인한 공문 공통시간을 씁니다. `인정시간`·`이수시간`·`인증시간`을 같은 우선순위로 인식하며, 없으면 `교육시간`을 사용합니다. `인증시간`은 오타로 간주했다는 확인 안내를 표시합니다. 머리글의 모든 공백은 비교할 때 제거하므로 `인 정 시 간`, `이 수 시 간 ( 시 간 )`도 인식합니다. 교육시간을 실적인정 시간으로 사용해도 되는지 확인·적용 단계에서 검토하세요.

- `인정시간`/`교육시간`: `3시간`, `2시간 30분`, `90분`처럼 단위를 적습니다.
- `인정시간(시간)`/`교육시간(시간)`: 숫자 `3`, `2.5`도 사용 가능합니다.
- `인정시간(분)`/`교육시간(분)`: 숫자 `90`은 1시간 30분입니다.
- 시간 컬럼이 있는데 빈칸·형식 오류면 공문 값으로 대체하지 않습니다. 대상자 표에서 단위와 함께 수정 후 **시간 적용 → 교육정보 확인·적용**을 누르세요.
- 같은 우선순위 시간 컬럼이 여러 개면 파일에서 사용할 컬럼 하나만 남기세요. 시간/분을 별도 두 컬럼으로 합산하는 형식은 아직 지원하지 않습니다.
- ‘차수별 3시간 인정’은 차수당 후보로 표시합니다. 참석 차수에 따른 총시간을 자동 계산하지 않습니다.

시간 별칭은 공문의 콜론 항목에도 적용됩니다. 동의어 시간 컬럼이 여러 개면 값이 같아도 임의 선택하지 않습니다. `(시간)`·`(분)` 단위 규칙은 모든 시간 별칭에 동일하게 적용됩니다.

개인별 시간 컬럼이 있으면 검토 화면의 공통 시간·분 입력칸은 숨깁니다. 교육명·일자·학습방법·교육유형을 확인·적용하세요. 명확한 0시간(숫자 0 포함)은 Excel에서 제외하고 제외 인원을 표시합니다. 빈칸·형식 오류는 0으로 간주하지 않으며 이름·명단 행·사유를 안내합니다. 모두 0이면 파일을 생성하지 않습니다.
